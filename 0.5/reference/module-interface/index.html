Module interface reference¶

This page lists what a SightPress module can use: the sightpress/module-interface package (0.5.0). A module depends on this package only, never on sightpress/core. To install one, see Add a module. To build one step by step, follow the Create a module tutorial.

What a module registers¶

A module implements ModuleInterface: manifest() says who it is, and register(ModuleRegistrar $registrar) adds what it brings. Each method of the registrar gives one kind of thing:

Method What it adds
services() Adds services to the site's service container.
routes() Adds HTTP routes.
blockTypes() Adds block types that editors can use in page content, variants of existing block types, and icons.
permissions() Adds permissions to the site's permission catalogue.
migrations() Adds the module's database migrations.
adminMenu() Adds entries to the admin navigation.
views() Adds a folder of templates under a namespace, so templates can refer to them as @<namespace>/<file>.
subscribers() Adds event listeners.
commands() Adds commands to the bin/sightpress console.
settings() Adds site settings.
search() Site search: document providers and an optional back-end (since 0.4).
dashboard() Admin dashboard widgets (since 0.4).
assistant() AI assistant providers and tasks (since 0.4).
seo() Public pages for the sitemap and llms.txt (since 0.5).
sms() Text message (SMS) providers (since 0.5).
schedule() Background work for schedule:run (since 0.5).
translations() Translations of the module's interface text (since 0.5).

Events¶

A module listens to an event with $registrar->subscribers(). Events are in SightPress\Module\Event; values that core keeps as enums travel as strings.

Event When Fields
AccountChanged Details of an account changed (by the person or by an admin). fields (array), userId (int), changedBy (?int)
AccountRegistered Someone signed up and confirmed their email address. userId (int), role (string), refusedRole (?string)
AnalyticsDataDeleted The site's visit statistics were deleted. actorId (?int)
AssistantUsed The AI assistant answered (or failed to answer) a request. actorId (?int), task (string), provider (string), model (string), inputTokens (int), outputTokens (int), outcome (string)
LocaleRemoved A language was removed from the site. locale (string), actorId (?int)
MediaChanged Details of a media item changed. fields (array), mediaId (int), changedBy (?int)
MediaDeleted A media item and its files were deleted. mediaId (int), originalName (string), deletedBy (?int)
MediaUploaded A file was added to the media library. mediaId (int), key (string), kind (string), uploadedBy (?int)
MenuChanged An entry of one of the site's menus was added, removed, moved or changed. menu (string), change (string), itemId (int), pageId (?int), url (?string), actorId (?int)
PageCloned A page was copied as a new draft. pageId (int), sourceId (int), clonedBy (?int)
PageCreated A page was started, in its first language. locale (string), pageId (int), authorId (?int)
PageMoved A page was moved to another place in the page tree (its address may have changed with it). pageId (int), fromParentId (?int), toParentId (?int), position (int), revision (int), movedBy (?int)
PagePurged Pages were deleted for good (emptied from the trash). pageIds (array), pageId (int), title (string), purgedBy (?int)
PageSaved A page's text in one language was saved as a new revision. locale (string), pageId (int), revision (int), savedBy (?int)
PageScheduled A page's publishing schedule was set, changed or cleared. publishAt (?DateTimeImmutable), unpublishAt (?DateTimeImmutable), pageId (int), actorId (?int)
PageTransitioned A page went through a workflow step: sent for review, approved, published, unpublished, archived, put in the trash … Part of the stable event list (1.0 API). pageId (int), transition (string), from (string), to (string), actorId (?int), comment (?string)
RedirectChanged A redirect (or a "gone" answer) was added or removed. locale (string), change (string), from (string), to (?string), actorId (?int)
RevisionRestored An older revision of a page's text was restored as a new revision. locale (string), pageId (int), restored (int), revision (int), restoredBy (?int)
RoleChanged Someone's role on the site changed. userId (int), changedBy (?int), from (?string), to (string)
ScheduledStepFailed schedule:run couldn't publish or unpublish a page at its scheduled time. pageId (int), transition (string), reason (string), scheduledBy (?int)
SettingsChanged Site settings were saved. keys (array), actorId (?int)
SiteModuleChanged A module was turned on or off for the site, or its data was deleted. moduleId (string), name (string), change (string), actorId (?int)
ThemeApplied The site switched to another theme. themeId (string), name (string), previous (?string), actorId (?int)
ThemeColoursChanged The site's own colours for its theme changed. colours (array), themeId (string), name (string), actorId (?int)
TranslationPublished A translation of a published page was published, or made a draft again. locale (string), pageId (int), published (bool), revision (int), actorId (?int)

Every part of the contract¶

By area (namespace under SightPress\Module).

Access¶

Name Kind What it is
Permission class Something a role can be allowed to do, for example page.publish.
Viewer class Who is making the request: their account id and their permissions on this site.

Admin¶

Name Kind What it is
AdminMenuItem class One entry in the admin navigation, linking to a named route.

Assistant¶

Name Kind What it is
AssistantConnection class How a provider reaches its service for one site: the site's (or tenant's) API key and, for custom endpoints, a base URL.
AssistantContext interface What an assistant task may need to know about the request it answers.
AssistantFailure enum Why an assistant call failed.
AssistantImage class An image sent with a message, for providers and models that can see images (alt text suggestions).
AssistantMessage class One message of an AssistantRequest.
AssistantProvider interface An AI service the optional assistant can use, with the site's own key (bring your own key).
AssistantRequest class Everything a provider sends to its model for one answer.
AssistantResponse class A model's answer, as the provider got it.
AssistantRole enum Who a message in an AssistantRequest comes from.
AssistantSuggestion class A checked answer, ready to show with Insert, Copy, Try again and Discard.
AssistantTask interface One thing the assistant can help with, for example a page summary or alt text for an image.
ProviderCapabilities class What a provider's model can do besides text.
StreamingAssistantProvider interface A provider that can also stream an answer as it is written.
TokenUsage class Tokens a provider counted for one answer, as it reports them.

Audit¶

Name Kind What it is
AuditRecord class One line of the site's audit log, written by a module through AuditTrail.
AuditTrail interface Writes to the site's audit log, which admins read on the Audit log screen.

Block¶

Name Kind What it is
A11yIssue class An accessibility problem found in one block's data by an A11yRule.
A11yRule interface An accessibility check on one block's data, for example "an image needs alt text or must be marked decorative" or "a video needs a captions track".
A11ySeverity enum How serious an accessibility issue found in block data is.
BlockContext interface What a block type may need to know about where it is rendered.
BlockIcon class An icon that blocks with icons can show, such as a brand logo in social_links.
BlockOption enum Shared options a block type can offer editors, stored in each block's own data and drawn by core as classes on the block's wrapper (never inline styles), which the theme styles through its tokens.
BlockStyles class The looks and shared options a block type offers (StyledBlockType::styles()).
BlockType interface A kind of content block (heading, image, video, call to action …) that editors can put on a page.
BlockVariant class A named look of a block type, such as card for a quote.
StyledBlockType interface A block type with variants or shared options (since 0.5).

Console¶

Name Kind What it is
Command interface A bin/sightpress console command added by a module.
CommandInput interface The parsed command line, as declared by Command::parameters().
CommandOutput interface Where a command writes its messages.
CommandParameter class One argument, option or flag of a console command, shown in the command's help and used as a question when someone runs the command at a terminal.
CommandParameterType enum How a command parameter is given on the command line.

Dashboard¶

Name Kind What it is
DashboardContext interface What a dashboard widget may need to know about the person looking at the dashboard.
DashboardWidget interface A box on the admin dashboard, for example "Last 7 days" from analytics.

Exception¶

Name Kind What it is
AssistantException class Thrown by assistant providers and tasks when a call can't give a usable suggestion.
InvalidValueException class Thrown when a value object of this package is built with a value that breaks one of its rules.
SmsException class A text message provider call failed.

Http¶

Name Kind What it is
AdminScreen class A module's admin screen, rendered by Screens::admin() inside the admin panel: core draws the navigation, skip link, notices and the <h1> with the title; the module's template draws only what goes under it.
PublicScreen class A module's public page, rendered by Screens::public() in the site's theme, with its menus, skip link, language links and footer; the module's template draws the main content, starting with its <h1>.
Screens interface Renders a module's screens the way core renders its own, so they share the admin panel or the site's theme, its accessibility features and its security headers.

Migration¶

Name Kind What it is
MigrationProvider interface Tells core where a module's database migrations are.

Module¶

Name Kind What it is
ModuleInterface interface A SightPress module: core's own features and third-party extensions alike.
ModuleManifest class What core needs to know about a module before it registers anything: who it is, its version, which modules it needs and whether it can be turned off.
ModuleRegistrar interface Passed to ModuleInterface::register(): one typed sub-registrar per kind of thing a module can add.
ModuleRequirement class One module that another module needs, with the versions it works with.

Notification¶

Name Kind What it is
NotificationChannel enum How a notification reaches a person.

Registrar¶

Name Kind What it is
AdminMenuRegistrar interface Adds entries to the admin navigation.
AssistantRegistrar interface Adds providers and tasks to the optional AI assistant.
BlockTypeRegistrar interface Adds block types that editors can use in page content, variants of existing block types, and icons.
CommandRegistrar interface Adds commands to the bin/sightpress console.
DashboardRegistrar interface Adds widgets to the admin dashboard.
MigrationRegistrar interface Adds the module's database migrations.
PermissionRegistrar interface Adds permissions to the site's permission catalogue.
RouteRegistrar interface Adds HTTP routes.
ScheduleRegistrar interface Adds background work that schedule:run does for each site where the module is on (since 0.5).
SearchRegistrar interface Adds content to site search, or replaces the search back-end.
SeoRegistrar interface Adds a module's public pages to the sitemap and llms.txt (since 0.5).
ServiceRegistrar interface Adds services to the site's service container.
SettingRegistrar interface Adds site settings.
SmsRegistrar interface Adds a text message (SMS) provider that site admins can choose (since 0.5).
SubscriberRegistrar interface Adds event listeners.
TranslationRegistrar interface Adds a module's translations of its interface text (since 0.5).
ViewRegistrar interface Adds a folder of templates under a namespace, so templates can refer to them as @<namespace>/<file>.

Routing¶

Name Kind What it is
Route class One HTTP route: a path, the methods it answers and the PSR-15 handler that answers it.

Schedule¶

Name Kind What it is
ScheduleRun class One run of schedule:run for one site, passed to every ScheduledJob.
ScheduledJob interface Work a module does in the background, on every run of schedule:run (the operator runs it every minute, from cron or the scheduler container), once per site where the module is on.

Search¶

Name Kind What it is
SearchBackend interface Stores the search index of one site and answers queries.
SearchDocument class One searchable thing in one locale, for example one translation of a page, as plain text.
SearchDocumentProvider interface Turns a module's content into SearchDocuments, so site search can find it.
SearchHit class One result: the document that matched, how well, and which words in it matched.
SearchIndexStatus class How many documents a back-end holds in one locale, and when it last indexed one.
SearchPerformed class Event dispatched by core after each site search, so other modules (analytics) can count searches.
SearchQuery class What a visitor searched for, in which locale, what they may see, and which page of results they want.
SearchResults class One page of results for a SearchQuery, best first.
SearchVisibility enum Who may find a document in site search.

Seo¶

Name Kind What it is
SeoEntry class One public page of a module, as search engines and AI readers should see it: listed in the sitemap and in llms.txt, and, when the module renders it with \SightPress\Module\Http\PublicScreen, described in its <head> (description, canonical address, other languages, schema.org JSON-LD).
SeoProvider interface Lists a module's public pages for the sitemap and llms.txt.

Setting¶

Name Kind What it is
Setting class A per-site setting of a module.
SettingType enum The kind of value a setting holds; core picks the form control from it.
SettingValues interface Reads the site's settings, typed as their SettingType says, with the registered default when none was saved.

Site¶

Name Kind What it is
SiteInfo class The site a request or command works on.

Sms¶

Name Kind What it is
PhoneLineType enum What kind of line a number is, from a provider's lookup.
PhoneLookupResult class What a provider knows about a number before anything is sent to it.
PhoneNumber class A phone number in E.164 form (+447700900123).
SmsCapabilities class What a provider can do, so core only offers what works.
SmsConnection class A site's account with a provider.
SmsDeliveryStatus enum
SmsEncoding enum How a text message is encoded, which sets how many characters fit in one message part.
SmsFailure enum Why a provider call failed, so core can tell people in plain language what to do.
SmsMessage class One text message to send.
SmsOptChange class Someone replied STOP (or START) to the site's messages.
SmsProvider interface A text message (SMS) service a site can send through.
SmsPurpose enum Why a text message is sent.
SmsReceipt class A provider's report that a message was delivered, or that it failed.
SmsResult class The provider accepted a message for delivery.
SmsWebhooks interface A provider that tells the site about delivery and replies by calling a webhook.

Text¶

Name Kind What it is
Message class Text for a person to read, translated by core into the reader's language when it is shown: screen titles and notices, for example.
