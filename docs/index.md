# SightPress documentation

SightPress is a powerful content management system (CMS) for everyone, designed with blind and low-vision
creators and audiences in mind. It is built on modern, object-oriented PHP and is free software, licensed
under the GNU General Public License v3.0 or later.

With SightPress you can run many websites from one installation, each in as many languages as you need.
The admin area, the default theme and every built-in feature aim to meet the Web Content Accessibility
Guidelines (WCAG) 2.2 at level AA. Every task works with a keyboard alone and with a screen reader.

## Status

SightPress is in early development. There is no release yet, and these pages will grow as features are built.

## Where to go next

- The source code lives on GitHub in the [SightPress organisation](https://github.com/sightpress).
- To run SightPress on your own computer, follow [Getting started](getting-started.md).
