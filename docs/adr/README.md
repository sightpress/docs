# Architecture Decision Records

Shared SightPress decisions are recorded in the `core` repo, in `docs/adr/`.

This folder is for decisions about the documentation site itself (structure, versioning, tooling).
It is excluded from the published site (`exclude_docs` in `zensical.toml`).

Use the same format and rules as `core`: file names `NNNN-short-title.md`, start from core's
`0000-template.md`, statuses *Proposed*, *Accepted*, *Superseded by …* or *Rejected*.
