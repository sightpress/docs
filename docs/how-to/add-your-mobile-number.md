# Add your mobile number

When a website has [text messages](set-up-text-messages.md) on, you can add your mobile number to your account. It is
up to you: you need it only to get notifications by text, to [sign in with your phone](sign-in-with-your-phone.md)
and, on websites that ask for it, to [confirm important changes](confirm-important-changes.md).

## Add it

1. Sign in. If you have no number yet, the website asks **Add your mobile number** straight away. You can choose
   **Skip for now** and add it later from **My account → Mobile number and text messages**.
2. Choose your **Country**, then type your **Mobile number** the way you usually write it, for example
   `07700 900123`. A number that starts with `+` and the country code works too.
3. Choose **Send the code**. The website checks it is a mobile number, then sends you a text with a 6-digit code.
   The text never contains a link.
4. Type the code in **6-digit code** and choose **Confirm my number**. You should see "Your mobile number is now …".

If the website says it isn't a mobile number, check that you didn't type a landline. If the provider didn't answer in
time, try again in a minute.

## Choose your text messages

Having a number signs you up for nothing. On the same page, tick **Send me text messages**, choose which ones you
want, and choose **Save my choices**. Untick it to stop them, or reply STOP to any of our texts.

## Change or remove it

On **My account → Mobile number and text messages**, type a new number to change it (the old one stops working at
once, also for signing in), or choose **Remove my number**.
