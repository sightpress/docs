# Confirm important changes

A website can ask for a **code by text message** before important changes, so a stolen password alone can't change
who runs it. This is called two-step confirmation. It needs [text messages](set-up-text-messages.md).

## What counts as important

Changing your password, email address or mobile number; inviting an admin or editor; changing someone's role or
deactivating them; editing roles; who can read the website and who may sign up; security settings; turning features
on or off; the AI assistant's key; cloud storage; deleting analytics data.

## Turn it on (admins)

1. [Add your own mobile number](add-your-mobile-number.md) first. Without it you can't confirm anything.
2. Go to **Site settings → Security**.
3. Choose **On: important changes need a code sent by text message** and **Save**.
4. Choose **Send me a code**, type the code from the text, then **Make the change**. You should see "Two-step
   confirmation is on."

Your organisation may have decided for every website: then the page says so and has no switch.

## Make an important change

1. Make the change as usual, for example change your email address.
2. You see **Confirm it's you**. Nothing has changed yet.
3. Choose **Send me a code**, type the 6-digit code from the text, and choose **Confirm**.
4. Choose **Make the change**. For a change that needs your password, choose **Go back to the form** and type it
   again: passwords are never kept.

For the next 10 minutes, in the same browser, other important changes don't need another code.

If you have no mobile number yet, the website asks you to add one first. There is no way round it by email.

## If no code comes

- Wait a minute and choose **Send a new code**.
- If you replied STOP to our texts before, reply **START** to our last text.
- If the page says it can't send a code right now, ask whoever runs your websites: they can make the change for you
  from the command line.
