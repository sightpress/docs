# Restore an older version of a page

Every time a page is saved, SightPress keeps a version of it. You can see who saved each version and when, read what
changed, word by word, and bring an older version back. Restoring never publishes anything.

You need to be able to change the page: a **contributor** for your own drafts, or an **editor** or **admin**.

## See the older versions

1. Choose **Pages** in the admin menu, then the page.
2. Next to the page's state, choose **Older versions**. You should see a table of versions, newest first: the
   version number, when it was saved (in your own time zone), who saved it, and the state the page was in then.
   "The system" means a change made from the command line or on a schedule.

On a website in several languages, each translation has its own versions. Links at the top of the screen lead to the
versions in each language.

## See what changed

1. Choose a version number, for example **Version 3**. You should see what changed since the version before it: first
   the details of the page (title, address, summary, search fields), then each block, under a heading that says
   whether it was changed, added, removed or has no changes.
2. Inside a field, words that were taken out read "[removed: …]" and are crossed out; words that were put in read
   "[added: …]" and are underlined.

The words "removed" and "added" are always written out, so the comparison reads the same with a screen reader, in
high contrast mode and without colours.

## Bring a version back

1. On the version's screen, choose **Restore version 3** (with that version's number).
2. You should see "Restored version 3 as version 5. Nothing was published: the page is still a draft." The newer
   versions stay in the list, so you can change your mind.

Restoring brings back the title, address, search fields and blocks. It doesn't change the layout, who can read the
page or its place on the website.

**While the page is published, restoring is refused**, because visitors would see the old text straight away. Choose
**Unpublish** first (or make that translation a draft), restore the version, check it, and publish again.

A version with a block that no longer exists can't be restored: copy what you need from it instead.
