# Codes we send you

A SightPress website **never sends you a link** to click. When it needs to check that an e-mail address is yours,
it sends a **6-digit code** instead, and you type that code on the website yourself.

This keeps you safe from fake messages. If you ever get a message that claims to come from a SightPress website and
asks you to click a link, it is not from us. Don't click it.

## When you get a code

You get a code by e-mail when:

- you **forgot your password** and asked for a new one: the code works for 15 minutes;
- someone **invited you** to help with a website: the invitation code works for 7 days.

The person who sets up a new website gets a **setup code** from the command line tool, not by e-mail. They pass it
on to the website's first admin, who uses it to choose a password. A setup code works for 7 days.

Each code works only once.

## What a code message looks like

- The subject names the website, for example "Your code to reset your password for Riverside Library" or "Ada
  invited you to Riverside Library". The code itself is never in the subject.
- The message has the code on its own line, for example `123 456`.
- The message has no links, no web addresses and no pictures.
- It ends with: "We will never send you a link. Type this code on the page where you asked for it. Never share it
  with anyone."

## Type a code

1. Go to the page that asked for the code. For a password, that is the page you are already on. For an invitation,
   go to the website's sign-in page and choose **Accept an invitation**.
2. Find the field called **6-digit code**.
3. Type the 6 digits. You can type them with or without the space in the middle.
4. Choose **Continue**. The page never sends the code by itself, so take your time.
5. You should see the next step, for example a page where you choose your password.

## If the code doesn't work

- Check the digits and try again. After 5 wrong tries the code stops working.
- A code also stops working when it is too old, when it has been used, or when you asked for a newer one.
- On the password page, choose **Send a new code**. You can ask for a new code once a minute; if it is too soon,
  the page tells you how many seconds to wait.
- For an invitation, ask the person who invited you to invite you again.
- For a setup code, ask the person who set up the website for a new one.
