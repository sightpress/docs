# How-to guides

Each guide shows you how to do one thing with SightPress, in short, numbered steps. They assume you have already
followed [Getting started](../getting-started.md), so SightPress is downloaded and runs on your computer.

## Your website

- [Create a website](create-a-site.md) with the command line tool, and give its first admin a setup code.
- [Write and publish a page](write-and-publish-a-page.md), from a draft through review to the public website.
- [Turn features on or off](turn-features-on-or-off.md) for one website, and delete a feature's data.

## Running SightPress

- [Run SightPress in the background](run-in-the-background.md), so that you can close the terminal.
- [Change the ports SightPress uses](change-the-ports.md), if another program already uses them.
- [Start a database server](start-a-database.md): MySQL, MariaDB or PostgreSQL.

## Checking the built-in tools

- [Open the test e-mail inbox](open-the-test-email-inbox.md), which catches every e-mail SightPress sends.
- [Open the file storage console](open-the-file-storage-console.md), which later versions will use for uploaded files.
- [Try the command line tool](try-the-command-line-tool.md).

## Signing in

- [Codes we send you](codes-we-send-you.md): why SightPress never sends links, and how to type a 6-digit code.

## Reference

- [Roles and permissions](../reference/roles-and-permissions.md): what admins, editors, contributors and members can do.
- [Blocks](../reference/blocks.md): every kind of content block and its fields.
- [Search and AI visibility](../reference/search-and-ai.md): how pages appear in search engines and AI search.
- [Command line reference](../reference/command-line.md): every command of `bin/sightpress`.
