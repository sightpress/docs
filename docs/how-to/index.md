# How-to guides

Each guide shows you how to do one thing with SightPress, in short, numbered steps. They assume you have already
followed [Getting started](../getting-started.md), so SightPress is downloaded and runs on your computer.

## Running SightPress

- [Run SightPress in the background](run-in-the-background.md), so that you can close the terminal.
- [Change the ports SightPress uses](change-the-ports.md), if another program already uses them.
- [Start a database server](start-a-database.md): MySQL, MariaDB or PostgreSQL.

## Checking the built-in tools

- [Open the test e-mail inbox](open-the-test-email-inbox.md), which catches every e-mail SightPress sends.
- [Open the file storage console](open-the-file-storage-console.md), where uploaded files will be kept.
- [Try the command line tool](try-the-command-line-tool.md).

## Coming later

SightPress is in early development. You can't create a website or put SightPress on a public server yet. Guides
for those tasks will appear here when the features are ready.
