# Report a problem

If something in SightPress doesn't work, shows an error, or stops you from doing something with your keyboard,
screen reader, zoom or colour settings, please tell us. You don't need to know which part of SightPress is at fault.

## What to tell us

Whichever way you report it, these help us most:

1. What you were trying to do, for example "publish a page in Spanish".
2. What happened. Copy any error message as text.
3. What you expected to happen.
4. The SightPress version, if you know it, and your browser and operating system.
5. For an **accessibility barrier**: your assistive technology and its version, if you use one, and what was
   announced or what happened.

Accessibility barriers are always treated as bugs, never as feature requests.

## Report it by email (no GitHub account needed)

1. Write an email to <contribute@sightpress.org>, in any format that suits you: text, a voice recording or a
   document. Write in your own words; imperfect English is welcome.
2. A maintainer replies within 5 working days, adds the report to GitHub for you, and tells you what happens next.

## Report it on GitHub

If you have a GitHub account:

1. Go to [open an issue in SightPress core](https://github.com/sightpress/core/issues/new/choose). If the problem is
   in this documentation, use [the docs issues](https://github.com/sightpress/docs/issues/new/choose) instead; if you
   aren't sure, use core and we'll move it.
2. Choose **Report a problem**, or **Report an accessibility barrier**. Each form says which fields are required, in
   words.
3. Fill in the form and choose **Submit new issue**.

A maintainer replies, asks for anything that is missing and labels the issue.

## Security problems

Never report a security problem in public. Email <security@sightpress.org>, or use **Report a vulnerability** on the
*Security* tab of the repository on GitHub. We acknowledge every report within 5 working days.

## Problems with people

To report behaviour that breaks the
[Code of Conduct](https://github.com/sightpress/docs/blob/main/CODE_OF_CONDUCT.md), email
<conduct@sightpress.org>. Reports are confidential.
